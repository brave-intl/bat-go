# Security Policy

## Reporting a vulnerability

Vulnerabilities in this repository must be reported through the Brave bug bounty program on HackerOne: https://hackerone.com/brave. Do not open public issues for security vulnerabilities.

## Closed report dispositions

Closed reports re-verified against this codebase, and the re-report policy that applies to them, are recorded in [docs/skus-security-audit-closed-reports.md](docs/skus-security-audit-closed-reports.md).

## Wallet v3 endpoint retirement

The removal of the unauthenticated v3 wallet GET routes, the client evidence behind it, and the disposition for related reports are recorded in [docs/wallet-v3-endpoint-retirement.md](docs/wallet-v3-endpoint-retirement.md).
